AI helper

Ready-to-copy prompts that use Kiva's current reading history and wishlist. Open ChatGPT, paste the prompt, and ask it to do the research.

1. Add a complete author / series catalogue

Use this when you want AI to prepare a verified list of books by an author. It requests a consistent import format.

Expected output format — one book per line:
Author | Series name (or Standalone) | Book sequence number | Book title | Publication year (if known)

For a series, sequence numbers must reflect the recommended reading order. Separate different series by the same author. Do not invent titles or include uncertain books without marking them.

2. Suggest Kiva's next books

Uses read books to avoid duplicates and considers the current wishlist.

3. Review content suitability

Ask AI to check potentially mature themes before buying a title.

Bulk catalogue prompt output can be pasted into Authors & books → Add a set of books. That importer accepts one title per line, or Title | Series. The full five-column format is intended as a reviewable AI result; add the approved titles using the bulk form.
